## PROJETO

O **Linkverse Guito TRFZ** é o hub de links oficial desenvolvido para o rapper **Guito TRFZ**, centralizando plataformas de streaming, lançamentos em destaque, o movimento **BECO** e os canais oficiais do artista em uma única interface.

Mais do que um agregador genérico de links, o projeto foi construído como uma extensão da identidade visual e da estética underground do artista, priorizando impacto visual, performance e uma experiência de navegação fluida em dispositivos móveis — principal ponto de acesso do público vindo das redes sociais.

A implementação utiliza a arquitetura **[AXIS](https://github.com/lvcascouto/axis)**, empacotamento com **Vite**, design tokens e um sistema visual próprio, com foco em performance, acessibilidade e consistência de interface.

🌐 [Acesse o Linkverse](https://guitotrfz.vercel.app/)

## DESTAQUES TÉCNICOS

- **Tipografia com recorte de textura** — aplicação de `background-clip: text` no título principal, utilizando uma textura grunge para reforçar a estética visual da marca, com fallbacks sólidos para preservar a legibilidade em diferentes navegadores.
- **Performance e carregamento otimizado** — priorização do carregamento do ativo visual principal e carregamento sob demanda de recursos secundários, contribuindo para uma abertura mais rápida e para a redução de deslocamentos inesperados no layout.
- **Acessibilidade semântica** — estrutura baseada em HTML semântico, hierarquia de conteúdo consistente, descrições alternativas para imagens e suporte à navegação por teclado e leitores de tela.
- **Navegação segura** — links externos configurados para abertura em novas abas com `target="_blank"` e `rel="noopener noreferrer"`, mantendo o contexto de navegação e reduzindo riscos relacionados à abertura de páginas externas.
- **Experiência desktop-first** — interface desenvolvida para desktop inicialmente, mas rigorosamente adaptada para dispositivos móveis, com layout fluido, áreas de toque bem dimensionadas e espaçamento pensado para interações rápidas.
- **Design system tokenizado** — organização de cores, tipografia, espaçamentos e transições por meio de tokens SCSS, facilitando a manutenção e a expansão da identidade visual.
- **Otimização para compartilhamento** — implementação de metatags de título, descrição e imagem para melhorar a apresentação do Linkverse quando compartilhado em redes sociais e aplicativos de mensagem.

## LINKVERSE

O **Linkverse** é uma linha de hubs de links personalizados desenvolvida pela **LUCAS CODE**.

Cada projeto é criado individualmente para refletir a identidade visual, os objetivos e a estratégia digital de cada cliente ou artista, oferecendo uma alternativa mais personalizada e profissional aos agregadores de links tradicionais.

A proposta combina organização de conteúdo, presença visual e direcionamento para os principais canais de uma marca ou profissional.

Este repositório representa o **segundo case oficial do produto Linkverse**, ao lado do [Linkverse M&A Consultoria Câmbio](https://github.com/lvcascouto/linkverse-ma).
